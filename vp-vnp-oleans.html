    How they were built

    Source. anthropics/formal-math/vp-vnp at commit 11b6c7e3c927df2658f513b6b68ea7f8929c62c5 (tree SHA b076b4b081298c4e909bac3f87f0e4462d1fb2cb), with the toolchain and dependencies pinned by its own lean-toolchain and lake-manifest.json.

    Direct parallel compilation (200 cores). Following the same sandboxed workflow used for our Riemann Hypothesis verification, each of the 323 modules was compiled directly by the pinned lean v4.33.1 binary in topological dependency order inside a network-isolated systemd sandbox (AllowedCPUs=0-199, read-only toolchain and Mathlib):

    lean --tstack=400000 <Module/Path>.lean -o lib/<Module/Path>.olean --setup <json>

    with the exact setup options from lakefile.toml:

    {"name": "<Module.Name>", "package": "vp-vnp", "isModule": false,
 "options": {"autoImplicit": false},
 "importArts": {}, "dynlibs": [], "plugins": []}

    Dependencies were not rebuilt. Notice that vp-vnp pins the exact same Lean toolchain (v4.33.1) and all nine Lake packages (including Mathlib 0df444a3) as the alpo.ge RH development. The dependency .oleans are the official Mathlib build cache downloads, mounted read-only during compilation.

    Result. All 323 modules compiled cleanly in 180.0 seconds wall time with 0 errors and 0 retries. sorry warnings were emitted solely for the five intentional placeholders in Challenge.lean.
